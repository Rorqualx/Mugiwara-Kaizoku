# Full UI Audit Report — 2026-05-02

**Scope:** All 60 routes, 825 components, 180+ tRPC procedures  
**Dimensions:** Logic, Safety, Quality, Bugs, UX, Functionality, Interactivity  
**Total issues found: 128** (19 Critical, 23 High, 48 Medium, 38 Low)

---

## Executive Summary

The three most urgent problem classes:

1. **Unprotected tRPC mutations (Critical/High x18)** — 20+ mutations use `publicProcedure`, allowing unauthenticated users to delete manga, queue downloads, modify settings, and access private data. The Next.js middleware only protects page routes, not `/api/trpc/*`.

2. **Reader path traversal + memory exhaustion (Critical x2)** — The page-serving API skips traversal checks for absolute file paths, and loads entire ZIP archives into memory per page request (up to 500MB per concurrent reader).

3. **No app-wide error boundary (Critical x1)** — Any unhandled React error crashes the entire app with a white screen and no recovery.
